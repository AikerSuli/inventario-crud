# Inventario CRUD

CRUD de productos hecho con Node.js y Express. El proyecto se trabajó con Git Flow.

## Cómo ejecutarlo

```
npm install
npm start
```

Luego abrir http://localhost:3000

## Ramas

- `main`: versión final
- `qa`: pruebas
- `developer`: desarrollo
- `feature/...`: una rama por cada funcionalidad
- `hotfix/...`: correcciones
